# Project Overview 🚀

Hello Mehak! This is your **Employee Management System** mini-project. It's a professional tool we built together to help you manage employee records easily and securely.

## 📖 Introduction
This project is an **Employee Record Management System (EMS)** designed specifically for HR and Admin users. It solves the problem of manual paperwork by providing a digital, high-density dashboard where you can add, edit, search, and delete employee information in real-time.

## 🛠️ Tech Stack
We used the most modern and "premium" technologies to build this:
- **Next.js 15 (Frontend Framework)**: The latest version for super-fast performance and SEO.
- **Tailwind CSS 4 (Styling)**: For that sleek, dark-themed "glassmorphism" look.
- **TypeScript (Language)**: Ensures the code is stable and bug-free.
- **Lucide React (Icons)**: For those beautiful, modern icons you see in the UI.

## ☁️ Services Used
- **Supabase (Database & Auth)**: This is your backend. It stores all employee data and handles your secure login.
- **Vercel (Hosting)**: This is where your website lives online so anyone can access it via your link.
- **GitHub (Version Control)**: Where all your code is safely stored and tracked.

## 🏆 What makes this special?
- **CSV Export**: You can download all your data with one click.
- **Real-time Stats**: The "Total Staff" counter updates automatically.
- **Secure**: Only you (the Admin) can manage the records thanks to Row Level Security (RLS).
