# Employee Management System (EMS)

A modern, high-density, and premium Employee Record Management System built with **Next.js 15**, **Supabase**, and **Tailwind CSS 4**. This system is designed for HR and Admin users to efficiently manage employee records with a sleek, dark-themed interface.

### 🌐 Live Demo
**[ems-app-lyart.vercel.app](https://ems-app-lyart.vercel.app)**

## 🚀 Key Features
- **Admin-Only Access**: Secure role-based login system for HR and Administrators.
- **Full CRUD Operations**: Add, Edit, Delete, and View employees in real-time.
- **Real-time Analytics**: Live "Total Staff" counter synchronized with the database.
- **Export to CSV**: One-click download of the entire directory for reporting.
- **Premium UI**: Custom-styled dark theme with glassmorphism and subtle animations.

## 🛠️ Detailed Tech Stack
- **Framework**: [Next.js 15.1.9](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Database**: [Supabase PostgreSQL](https://supabase.com/)
- **Authentication**: [Supabase Auth](https://supabase.com/auth)
- **Backend Services**: Supabase Edge Functions & Row Level Security (RLS)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🔒 Security
- **React2Shell Patch**: Fully patched against CVE-2025-55182.
- **RLS**: Row Level Security ensures data isolation and protection.
- **Auth Middleware**: Secure route protection for all dashboard pages.
